# AI & ML Jobs Analytics Dashboard

This is my first Power BI dashboard project created to practice data visualization, KPI creation, and interactive reporting.

## Tools Used
- Power BI
- Excel / CSV
- Data Cleaning
- DAX

- Average Salary Analysis
- Median Salary Analysis
- Remote Job Insights
- Experience Level Analysis
- Location Insights
- Skills & Hiring Insights

## Key Learnings
- Creating KPI cards
- Building interactive dashboards
- Working with DAX measures
- Data visualization best practices
